# Contributing to Orrery

Reproduce a bug with the smallest scenario that demonstrates it. Include the app version, browser, integrator, timestep, gravity solver and whether shared or transferable memory was active. Do not include edit keys, private URLs, credentials, local databases or personal scenario data in a public issue.

Keep physics independent of React and preserve SI/J2000 state, worker ownership, revision gating and diagnostic-baseline contracts. Run focused tests for a changed subsystem, then the complete frontend/backend suites and build at a milestone.

Public content lives in site/content.mjs. Check scientific claims, links, headings, canonical metadata and /accuracy whenever a model changes. Run the SEO HTTP smoke test after routing changes.

No project-wide software license has been selected by the repository owner. Public source visibility is not itself a reuse license. Ask the owner to establish contribution/reuse terms before submitting substantial third-party code. Texture and catalog assets have their own documented licenses.
